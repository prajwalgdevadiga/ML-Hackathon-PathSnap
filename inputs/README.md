# Dataset setup

Copy the organiser-provided archives into this folder and leave them zipped. These archives are supplied separately from the GitHub package.

| Filename | Purpose |
|---|---|
| `Student folder.zip` | The 80 training trips and ten student-test trips used by the notebooks and student-test server |
| `evaluator_test.zip` | The ten reserved trips for the authorised evaluation run |

The Windows launcher expects those exact names. Place the reserved archive only on the server laptop for evaluation. Both files are ignored by Git. For installation and server commands, see [Run PathSnap on another laptop](../RUN-ON-ANOTHER-LAPTOP.md).
